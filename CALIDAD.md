# MATRIZ DE ATRIBUTOS DE CALIDAD Y ESTÁNDARES (SOMMERVILLE CAP. 24)

### 1. Mantenibilidad (Maintainability)

* **Métrica Objetivo:** El código deberá mantenerse ordenado y dividido en funciones sencillas para facilitar su comprensión y modificación.
* **Estándar de Codificación:** Se utilizará PEP 8 como guía para mantener un formato ordenado y uniforme en el código Python.
* **Nomenclatura:** Se utilizarán nombres claros y relacionados con la función de cada variable, función o elemento del programa.

### 2. Confiabilidad y Seguridad (Dependability & Security)

* **Validación de Entradas:** Los datos serán revisados antes de realizar el análisis para identificar información vacía, incorrecta o que pueda generar errores.
* **Control de Datos:** Se evitará incluir información sensible, contraseñas o datos de acceso dentro del código o repositorio del proyecto.

### 3. Eficiencia (Efficiency)

* **Uso de Memoria:** Se utilizarán herramientas y estructuras adecuadas para procesar los datos de manera eficiente, evitando operaciones innecesarias que puedan aumentar el tiempo de procesamiento.

### 4. Aceptabilidad (Acceptability)

* **Documentación de Funciones:** Las principales funciones utilizadas en el proyecto tendrán una explicación breve de su propósito para facilitar su comprensión por parte de los integrantes del equipo.
